# Massage Heaven — website

The website for Massage Heaven, a massage studio at ul. Krucza 16/22 in Warsaw. Built with [Astro](https://astro.build).

- Project guide for Claude Code and developers: [`CLAUDE.md`](CLAUDE.md)
- Design, behaviour and content docs: [`docs/`](docs/)
- Design source: [Figma](https://www.figma.com/design/J7HQH69jG2BbPrzjCWG5dx/Massage-Heaven)

- **Developer: start with [`docs/handoff.md`](docs/handoff.md).**

## Status
- **Phase 1 — done (2026-11-13):** the public one-page site, PL/EN/UA, desktop + mobile, plus an admin panel prototype (`/admin`, dev server only, sample data in the browser).
- **Phase 2 — developer:** storing voucher requests, the admin back end, hosting the voucher PDFs, deploy. See [`docs/handoff.md`](docs/handoff.md).

```bash
npm install
npm run dev     # http://localhost:4321
```
